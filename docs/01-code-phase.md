# Phase 2 — Code: learner checkpoints

1. Run the React UI and six APIs locally and visit their `/docs` routes.
2. Register as a seller; create a store; create a product; add a listing and stock.
3. Register as a customer; compare three sellers; order from one store.
4. Verify that the Inventory API returns reduced stock for **that specific store**.
5. Verify the Order API lists the order for the buyer and seller; verify an outbox record exists.
6. Run `pytest -q` and discuss failures.
7. Commit the code to GitHub using Git (no CI pipeline yet).

**Next DevOps step:** Build — explain Dockerfile and layers, create each image, then Compose for local end-to-end deployment.
